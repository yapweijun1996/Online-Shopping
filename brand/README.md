# Pomelo brand assets

The editable upstream source is `brand/` in the read-only Pomelo-STEM repository. This directory is a synced copy of Pomelo-STEM brand v2.1 at commit `871aee8`; keep artwork byte-identical to upstream. `logo-standard.json` records the approved tiers and seller/shop mappings. Run `node scripts/build-brand.js` to publish assets and `node scripts/check-brand.js` to check them.
