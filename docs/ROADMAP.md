# Roadmap

**Lifecycle: public Demo deployed; Production preparation in progress.** Milestones are dependency gates, not dates or claims of delivery. Each acceptance item in [SPEC.md](SPEC.md) moves through Planned → Implemented → Verified locally → Released to Production separately.

| Milestone | Depends on | Outcome and exit gate | Current state |
| --- | --- | --- | --- |
| M0 Evidence and documentation baseline | Repository review | Core documents, desktop/mobile previews, draft API, explicit open decisions, measured progress, and a goal prompt under 2,000 characters agree with code and tests. | Verified as a documentation milestone. Later MVP code and local tests are tracked separately under M1–M4 and the AC counts. |
| M1 Seller foundation | M0; credential, currency and image decisions | Build private backend/store, super admin login/session/authorization, catalog API, seller login and product management. Establish reusable locale selection and seller PWA shell. Verify AC-01–04 and seller parts of AC-17–18. | In progress: seller product API/editor, private schema v5, login/session and seven-language seller UI run locally; AC-01–04/18 are locally verified. Target-browser PWA installation remains AC-17. Optional localized product content is a later catalog extension. |
| M2 Public storefront | M1 catalog API | Build original responsive public catalog/search/detail and IndexedDB convenience cart. Add shop PWA shell and seven-language interface. Verify AC-04–05 and relevant AC-15/17/18 states on phone/desktop. | In progress: active-only catalog/detail, cart and same-browser reload, 320/390/1280px Chromium journeys and seven-language UI pass locally. AC-04/05/15/18 are locally verified; target-browser PWA installation remains AC-17. |
| M3 Guest checkout and seller review | M1–M2 | Implement AC-06–14: validated multi-destination checkout with +60/+65 buyer and recipient phones, optional on-device history, single-currency authoritative totals without shipping/GST, atomic order/idempotency receipt, seller queue/detail, revision-fenced confirm/reject, copy, and manual opted-in WhatsApp. Verify failure/concurrency/API and browser journeys. | Functional slice locally verified for AC-06–14: API/data tests and browser checkout, retry/storage failure, seller queue/detail, confirm/reject, two-tab stale recovery, copy feedback, opted-in link, and 320px order review pass. Full milestone exit still depends on M1–M2 cross-cutting quality gates. |
| M4 Production release readiness | M1–M3; Production hostname, server access and backup destination | Complete AC-15–18, contract/build/browser/accessibility/security, PWA and seven-language checks, private-data review, PostgreSQL migration, encrypted off-host backup and recovery, runtime health/readiness, deployment smoke, and rollback proof. Only then mark Production released. | In progress: the public Cloudflare Demo and local Docker/SQLite stack have smoke evidence. The owner recorded the order-retention basis. AC-16/17 still need a PostgreSQL deployment, backup/recovery and rollback proof, and target-device PWA install/update. |

## Deferred work

Payment, inventory/shipping automation, customer accounts/OTP and cross-device recovery, outbound WhatsApp automation, courier/AWB/tracking, and CSV/Excel batch export are outside these milestones. Verify any external platform/import contract before adding an integration milestone.
