# Seller Studio layout and color review

Two independent advisors reviewed the AI Studio generation screen and Seller Appearance. The lists preserve their proposals, including ideas beyond this release.

## AI Studio layout — 20 recommendations

1. Add an animated SVG loader to the active generation card.
2. Give queued cards a static clock and a reserved preview area.
3. Honor reduced motion with a static active icon and readable text.
4. Announce the current job and the number of previews ready when the batch ends.
5. Use one atomic polite batch announcement and hide decorative icons from assistive technology.
6. Leave unstarted styles visible when an error stops the batch.
7. Reserve the same aspect ratio for placeholders and completed previews.
8. Fit product images inside previews so no part of the product is cropped.
9. Keep the style title and status in predictable positions.
10. Use labels and icons so status is distinguishable independently of color.
11. Put the call estimate beside Generate on desktop and above it on phones.
12. Place Open product next to the selected product name.
13. Label the style fieldset “Image styles.”
14. Disable Generate when the selection is empty and explain how to enable it.
15. Give checked styles a selected surface, generous touch targets and visible keyboard focus.
16. Size the result grid by usable width, with a single column on small phones.
17. Shorten the permanent review note and explain storefront visibility next to Add to product gallery.
18. Give generation, advisory review and gallery confirmation separate visual treatments.
19. Name preview links by style and say when the link opens in a new tab.
20. Test long batches, partial failure, keyboard use, small screens and reduced motion.

## Appearance and dark mode — 20 recommendations

1. Keep system/light/dark mode separate from palette choice.
2. Use dark charcoal for the seller canvas, panels and navigation.
3. Scope seller dark tokens so each saved palette can define its accents.
4. Consider Graphite as a neutral default for new users.
5. Preserve Evergreen as a green accent option with neutral dark surfaces.
6. Give Ocean Blue cool blue interactive colors.
7. Make Warm Plum visibly distinct with plum accent and action colors.
8. Keep the orange action role in Navy Orange.
9. Give High Contrast the strongest control borders and focus ring.
10. Offer Graphite as a quiet, cool choice.
11. Separate accent text, action backgrounds and action foregrounds.
12. Keep semantic success, warning and error colors consistent across palettes.
13. Use a neutral sidebar and distinguish the selected item by marker, surface and weight.
14. Keep interactive outlines stronger than decorative dividers.
15. Style disabled and queued controls deliberately instead of relying on uniform fading.
16. Consider a temporary light/dark toggle within the palette preview.
17. Show surface and action colors in each swatch.
18. Use live action and status tokens in Appearance previews.
19. Match browser chrome to the Seller dark top bar.
20. Check color contrast, narrow and wide layouts, focus and preference persistence.

This release adds generation placeholders and progress, refines the control layout and applies neutral Seller dark tokens to all ten palette choices. Appearance supports previewing either mode before applying a palette. A different default palette remains a proposal.
