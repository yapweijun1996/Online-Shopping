## Successful order semantics

`public/shop/checkout.js` calls `onSuccess` after a real successful order response. `public/shop/app.js:completeOrder` saves the local receipt, subtracts the actually submitted quantities and navigates to `#receipt`, even if the buyer navigated meanwhile. This is the existing success contract and must be preserved. “Leave then never navigate” is not the acceptance rule for an already legitimate completed order. Stale reads/rejections, unsubmitted drafts and duplicate/new requests must still be isolated. Any proposal to change receipt navigation, idempotency, submission scope or authorization requires owner review first; this matrix does not authorize it.
